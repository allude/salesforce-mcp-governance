How to Set Up Your Okta OIDC Application
Follow these steps in the Okta Admin Console
  1. In Okta Admin Console, go to Applications → Applications → Create App Integration.
  2. Select OIDC - OpenID Connect and Web Application.
  3. Check Authorization Code and enable Require PKCE as additional verification.
  4. Set Sign-in redirect URIs to:
  5. If using group-based admin restriction, add a groups claim in Security → API → Authorization Servers → Claims matching .*.
  6. Paste your Issuer URL, Client ID, and Client Secret on the left and click Save.
